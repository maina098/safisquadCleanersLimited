# V Legendary Frontend

React dashboard plus the migrated Fabricspa public website.

- React dashboard: `/`
- Fabricspa home: `/fabricspa.com/index.html`
- Fabricspa pages: `/fabricspa.com/about-us/`, `/fabricspa.com/contact-us/`, `/fabricspa.com/our-stores/`, `/fabricspa.com/partner-with-us/`, and policy pages

Run with `npm run dev` from this directory.
